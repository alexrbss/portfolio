## Projetos

### Tutor de Algoritmos com RAG

MVP de um tutor educacional desenvolvido durante minha atuação como monitor de
Algoritmos e Programação I. A aplicação consulta materiais de apoio elaborados
para a disciplina, responde com fontes e oferece feedback formativo para
exercícios em Portugol, preparando a transição dos fundamentos para C.

**Acessos:** [Demonstração ao vivo](http://13.217.22.43) ·
[Código-fonte](https://github.com/alexrbss/chatbot-algoritmos)

**Tecnologias:** Python, Streamlit, RAG, BM25, Docker e AWS EC2.

Principais recursos:

- recuperação de trechos dos materiais com indicação das fontes;
- feedback baseado em rubricas para 20 exercícios da disciplina;
- ingestão automatizada e validada de materiais em PDF;
- modo público somente leitura e implantação reproduzível na AWS.
